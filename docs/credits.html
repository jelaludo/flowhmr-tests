What runs here

This is a browser animation viewer for non-commercial feedback. The AUREL retarget preserves the native rig and drives its muscle endpoints after posing. The optional PHC skeleton shows published human tracking; it does not simulate AUREL. Inference and licensed model downloads stay on the local workstation. No SAM or SMPL-H weights, body meshes, original private videos, credentials or machine paths are included.

Feedback is copied to your clipboard or opened as a draft GitHub issue when you choose. This static page has no upload form, analytics or feedback database. Loading an example requests its animation data from the FlowHMR project site.
